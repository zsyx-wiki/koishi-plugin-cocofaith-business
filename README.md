# Faith Business

Faith v3 的玩法层，强依赖 `faithCore`

## 内置玩法

- 信仰注册、信息、弃誓与职业
- 每日祈祷
- 虚空祈求与彩蛋
- 按物品或等级出售背包物品
- 创造者数值管理
- 恶魔轮盘：普通、赌徒、疯狂模式

```text
信仰 信息
信仰 注册 [信仰名]
信仰 弃誓 [目标信仰]
信仰 职业 [职业名]
信仰 变更职业 [职业名]
信仰 卖出 [物品名] [数量/全部]
信仰 卖出等级 [等级]
信仰 强制卖出等级 [等级]
虚空祈求 [次数]
虚空祈求 次数
```

每日祈祷使用各信仰自己的祷词，不占 QQ 指令面板位置。

## 配置

Koishi 配置定义集中在根目录 [`config.ts`](./config.ts)。`faith`、`voidPrayer` 和 `dailyPrayer` 可单独启停；其他模块使用 `modules.<name>` 配置。

## 恶魔轮盘

```text
恶魔轮盘 发起 / 发起赌徒 / 发起疯狂
恶魔轮盘 加入 / 退出
恶魔轮盘 开始 / 结束
恶魔轮盘 开枪 / 恐惧 / 无畏 / 退缩
恶魔轮盘 对局 / 状态
恶魔轮盘 强制结束
```

房主负责开局；开始前可解散，进行中仅创造者能强制结束。默认45秒未行动会代开一枪，同一玩家累计第二次超时淘汰。QQ回复次数用完、凭证过期或发送失败，都不会暂停游戏。发送“对局”或“开枪”可查看或继续当前状态；已结束时返回最后结果。

疯狂模式开局统一扣门票，一人不足则整个开局回滚，不会留下部分扣费。门票要求足额；淘汰罚款沿用 v2，可产生负余额。奖池按实际扣除的罚款累计，不把等级减免的部分算入奖池。强制结束按完整参与名单返还实际门票和已扣罚款，不发胜者奖励。

配置在 `roulette.config`：`turnSeconds`、`normalMin`、`gamblerMin`、`crazyMin`、`entryFee`。不新增指令面板项，不使用按钮。

## 房间与玩法扩展

新增组队玩法依赖 `rooms`，通过其公开接口注册游戏。房间服务负责群内互斥、加入与开局、门票、串行处理、计时及持久化；玩法负责规则和结构化结果。

房间和按 UID 索引的游戏战绩都由 `faith_business_rooms` 保存，使用不同主键。每次行动通过 Core 的多人原子事务同时提交房间版本、资产变化和战绩。其他业务不能直接查询此表，只使用房间接口。

接口与扩展示例见 [游戏房间开发说明](./docs/game-rooms.md)。
